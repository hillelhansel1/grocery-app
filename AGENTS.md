# Mandatory project rules

- Work on a scoped feature branch. Keep tests beside the source or in the owning app's test directory, and update them with behavior changes.
- Run relevant tests, lint, formatting and type checks before handoff. Report actual results and clearly identify skipped or blocked checks.
- Minimize token usage by reading only relevant files and keeping command output and summaries concise. Keep changes within the requested scope and avoid unrelated refactors or dependencies.
- Never create, expose or commit secrets. Do not use paid services or run destructive actions.
- Obtain explicit approval before pushing or deploying.
- Sprint 0 is scaffolding only. Do not implement business features or download AI models.
